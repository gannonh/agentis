Stub-boundary browser drive, HTTP/SSE retention checks, and both live-provider retention receipts for [KAT-3240](https://linear.app/kata-sh/issue/KAT-3240/gate-1-conversational-team-workflow-with-retained-results).

The browser drive ran against product tree `2a743bb2ef4f8513e51e3033c81f670b46900f75` on macOS arm64, Node 24.20.0, pnpm 9.15.9, Docker Desktop 29.3.1. It exercised the authenticated owner room with the repository Codex and Claude protocol stubs at boundary `unverified-host-scratch`. Mid-drive review found that the retained-task tabs displaced the room below the request panel at desktop widths; [commit `0196c8a1`](https://github.com/gannonh/agentis/commit/0196c8a18e10fbca345cd699deeed8d1f5d3475b) pins the room to the second column, and screenshots 11 and 12 were captured after rebuilding it. Live receipts were recorded on Sartre at product commit `b1f36df5ad8f0ca08fa964da6ad021aad236255e` with boundary `docker-desktop-run-container`; no product source changed after that commit (the later commits add receipts, skills, and this layout fix).

## Reproduction

The browser drive ran from this checkout with the repository stubs and no Docker or provider credentials:

```sh
pnpm install --frozen-lockfile
pnpm build
EVIDENCE_DIR="docs/verification/kat-3240/browser-<timestamp>"
DATA_ROOT="$(mktemp -d /tmp/agentis-browser-kat3240-XXXXXX)"
PORT="$(node --input-type=module -e 'import { createServer } from "node:net"; const s=createServer(); s.listen(0,"127.0.0.1",()=>{const a=s.address(); process.stdout.write(String(a.port)); s.close();});')"
ENDPOINT="http://127.0.0.1:$PORT"
AGENTIS_CODEX_STUB="$PWD/packages/cli/test/codex-stub.mjs" \
AGENTIS_CLAUDE_STUB="$PWD/packages/cli/test/claude-stub.mjs" \
node packages/cli/dist/bin.js serve --endpoint "$ENDPOINT" --data-root "$DATA_ROOT" --provider codex --execution-boundary unverified-host-scratch
node packages/cli/dist/bin.js web --endpoint "$ENDPOINT" --data-root "$DATA_ROOT"
```

Open the printed bootstrap URL, acknowledge both read-only sources, then follow [browser-conversation](../../../.agents/skills/verify-agentis/features/browser-conversation.md) and [handoff](../../../.agents/skills/verify-agentis/features/handoff.md). The cursor-expiry probe ran on a second fresh stub root with 52 submissions and the same public SSE route; the daemon restart test reused the first root on the same port. `pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm lint`, `pnpm test` (127 CLI tests, 11 environment-loader tests), `pnpm build`, and `pnpm pack:smoke` passed locally; GitHub Actions run 118 passed the same set at `2a743bb2` for Node 24.20.0 on linux-x64.

## Limits

- Interactive browser evidence and the expired-cursor probe are stub-boundary receipts (`unverified-host-scratch`). They prove the client, HTTP, persistence, and SSE contracts, not provider authentication or container behavior.
- The large-transcript check augments `GET /v1/status` through a temporary local proxy; the client and daemon are unmodified, but the 150 synthetic messages are fixture data, not provider output. Inner-transcript keyboard scrolling was not reproducible under the automation harness; Tab traversal and pointer scrolling were.
- Live provider receipts come from the Sartre run at `b1f36df5` with provisioned provider logins. Provider dropout, billing, and long-run reliability remain unverified, as the spec states.
- The expired-cursor probe recorded 128 replayed transitions at the floor; slow-subscriber backpressure is not separately measured beyond the duplicate-free bounded replay.
- Source integrations stayed read-only. Exact-action approval execution and real-resource mutation remain KAT-3244 and KAT-3241.
- External human usability and business value were not measured; the Gate 1 research prototypes remain simulated evidence.
- Commit `2a743bb2` carries repository tooling and policy files (agent skills, `.cursor` rules, `AGENTS.md`/`CLAUDE.md`) alongside this feature. It is a repository carry, not a product change, and is called out in the pull request body.
